# Results
CSV files contains the metrics calculated and timestamp for the test run
HTML files has a plotly dynamic responive plots
PNG files are the plots generated by matplotlib or seaborn

### directories 
- `testing/`: aggregated test artifacts and plots
    - `exp_1/`: results of Experiment 1
    - `exp_2/`: results of Experiment 2
    - `exp_3/`: results of Experiment 3
    - `predictions_vs_true/`: per-model prediction CSVs (Timestamp, True, Prediction)
- `training/`: training logs and training-phase outputs
- `models_description.txt`: brief model summaries

Generated by (examples):
- `offline_learn.py` → offline models, `models_description.txt`, offline prediction CSVs
- `online_learning.ipynb` → online training outputs, `training/` and online prediction CSVs
- `Experiments.ipynb` → combined comparison plots in `testing/exp_*`
